# CyberGuard CEP 🛡️
### Community Engagement Project: Phishing, Social Engineering & Customer Data Protection

A responsive, multi-lingual web platform built to educate citizens, students, and local businesses on modern digital fraud tactics, psychological social engineering traps, and customer data privacy regulations (DPDP Act 2023).

---

## 🌟 Key Features

- **Problem vs. Solution Matrix:** Root-cause analysis of phishing, smishing, "Digital Arrest" scams, QR code fraud, and enterprise data breaches.
- **National Awareness Video Gallery:** Embedded curated educational videos from Indian cyber regulators, RBI awareness campaigns, and cybersecurity experts.
- **Interactive "Spot The Phish" Simulator:** Interactive scenario-based simulator testing users against realistic SMS, email, and social engineering traps with immediate diagnostics.
- **Quick Vulnerability Assessment:** 4-question risk calculator providing users with personalized safety scores and actionable remediation steps.
- **Multi-Language Support (i18n):** Full support for **English**, **हिंदी (Hindi)**, and **मराठी (Marathi)** with an automatic initial language selection toast.
- **Light & Dark Theme:** Handcrafted, clean institutional styling with an instant theme toggle (☀️ / 🌙).
- **Emergency Action Protocol & Helpline 1930:** Clear guidelines for the "Golden Hour" response and direct linkage to `cybercrime.gov.in`.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```
2. Open `index.html` directly in any web browser, or launch a lightweight server:
   ```bash
   # Python 3
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser.
